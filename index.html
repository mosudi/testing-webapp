Testing & Deployment Checklist

This portfolio is engineered with standard web components (HTML/CSS/JS) with zero build tools required. It deploys out-of-the-box anywhere:

1

Local Chrome Testing with Five Server

Run Five Server (recommended in your VS Code) or Python python -m http.server 8080. Open Chrome at http://localhost:8080.

2

GitHub Pages / Vercel / Netlify Deployment

Simply drag and drop this project folder or push to a Git repository. No build command is needed; set the publish directory to root (./).

3

Chrome App / PWA Installation

In Chrome, look for the install icon in the address bar (or click "Install Chrome App" above) to run this portfolio in dedicated windowed standalone mode.
